🚀 Cómo hostear tu página gratis en Vercel

Esta aplicación está lista para Vercel sin ninguna configuración previa. Sigue cualquiera de estas dos opciones gratuitas:

1. Subir a GitHub y conectar a Vercel (Recomendado)

  1. Crea un repositorio en GitHub con esta carpeta.
  2. Inicia sesión en Vercel.com.
  3. Haz clic en "Add New Project" y selecciona tu repositorio.
  4. Vercel detectará el archivo index.html automáticamente. Haz clic en "Deploy".
  5. ¡En 5 segundos tendrás tu URL pública con HTTPS y actualizaciones automáticas!

2. Despliegue con Vercel CLI (Desde la consola)

Si tienes Node.js instalado, puedes ejecutar en esta carpeta:

npx vercel

Sigue las preguntas rápidas en la consola y tu sitio quedará en línea al instante.

3. Archivo vercel.json incluido

Ya incluimos un archivo vercel.json en el proyecto con las cabeceras de caché óptimas para archivos estáticos.
